# W3C SPARQL 1.0 (DAWG) tests that maplib currently fails (used by test_w3c_sparql10.py).
# One test id per line, optionally followed by "# reason".
# These are marked as strict xfails: when a test starts passing, remove it from this list.

# Most of these come from maplib storing literals of the XSD datatypes by value: lexical forms
# such as "01"^^xsd:integer, "1.0e0"^^xsd:double or "+1"^^xsd:integer are not kept (they come
# back canonical, e.g. "1"^^xsd:integer and "1.0"^^xsd:double), terms with the same value are
# the same term, and literals whose lexical form is not valid for their datatype
# ("xyz"^^xsd:integer) are dropped when the data is read.
